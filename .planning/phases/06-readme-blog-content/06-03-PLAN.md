**Action A: Measure live wire bytes**

Start the stack:
```bash
docker compose up -d
```

Wait for all services healthy (centrifugo, then bob roles, then alice roles):
```bash
docker compose ps
```

Wait until alice-classical and alice-pq have started (they exit after exchange — check logs):
```bash
docker compose logs --no-log-prefix alice-classical 2>&1 | tail -20
docker compose logs --no-log-prefix alice-pq 2>&1 | tail -20
```

Measure wire bytes from Prometheus endpoints. The histogram buckets show cumulative counts; use the _sum/_count to calculate average:
```bash
# Classical wire bytes
curl -s http://localhost:9091/metrics | grep "ratchet_message_wire_bytes"
curl -s http://localhost:9092/metrics | grep "ratchet_message_wire_bytes"

# PQ wire bytes
curl -s http://localhost:9093/metrics | grep "ratchet_message_wire_bytes"
curl -s http://localhost:9094/metrics | grep "ratchet_message_wire_bytes"
```

Also check handshake duration (to confirm metrics are being observed):
```bash
curl -s http://localhost:9091/metrics | grep "ratchet_handshake_duration_seconds_sum"
```

Record the actual wire byte values from the histogram buckets. Identify:
- Classical handshake initial message size: the _sum value from alice-classical when _count=1 (first send is the handshake initial message)
- PQ handshake initial message size: same from alice-pq
- Classical ratchet step size: subsequent _sum/_count ratio
- PQ ratchet step size: subsequent _sum/_count ratio

If the stack fails to start or metrics are not populated, check docker compose logs for errors and record the failure in the SUMMARY.
